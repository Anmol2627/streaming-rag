# Doc_16
### IT Security Policy — Password & Access Control

## §1 Purpose & Scope
This policy (internal reference SEC-014) establishes minimum password and access-control standards for all employees with access to company systems.

## §2 Password Complexity Requirements
Passwords must be a minimum of 12 characters and include at least one uppercase letter, one number, and one special character.

## §3 Password Rotation Schedule
Under policy SEC-014, passwords for all standard user accounts must be rotated every 90 days; privileged administrator accounts must be rotated every 60 days.

## §4 Multi-Factor Authentication Requirement
Multi-factor authentication is mandatory for access to email, VPN, and all cloud-hosted business applications.

## §5 Access Revocation on Offboarding
All system access must be revoked within 4 hours of an employee's final working day, coordinated between HR and IT via the offboarding checklist.

## §6 Shared Account Prohibition
Shared or generic login credentials are prohibited for any system that logs individual user activity; service accounts require a documented exception approved by IT Security.

## §7 Policy Exceptions Process
Any exception to this policy (SEC-014) requires written approval from the IT Security team and is reviewed quarterly for continued necessity.
