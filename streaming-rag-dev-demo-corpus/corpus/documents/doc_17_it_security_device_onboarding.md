# Doc_17
### IT Security Policy — Device Onboarding

## §1 Purpose & Scope
This policy governs the registration and security configuration of any device — company-issued or personal — used to access company systems.

## §2 New Device Registration
All company-issued laptops and mobile devices must be registered with IT before first use, which installs required endpoint security software automatically.

## §3 IT Security Training Requirement
Employees receiving a new company-issued device must complete IT security awareness training covering safe device usage within 5 working days of receiving the device, as part of standard onboarding requirements.

## §4 Mobile Device Management Enrollment
Any device used to access company email must be enrolled in the Mobile Device Management (MDM) platform, which allows remote wipe in the event of loss or theft.

## §5 Lost/Stolen Device Reporting
Lost or stolen devices must be reported to IT Security within 2 hours of discovery so that remote wipe and access revocation can be initiated immediately.

## §6 Personal Device (BYOD) Restrictions
Personal devices may access email and calendar only; access to internal file storage or engineering systems from personal devices is not permitted under any circumstance.
